| Campo | Valore |

| Versione | 0.1 — 2026-10-02 |

| GAP | GAP-H03 |
| Responsabile | Titolare con consulente |
| Riferimenti normativi | GDPR artt. 44–49; Decisione di adeguatezza (UE) 2023/1795 del 10 luglio 2023 (EU–US Data Privacy Framework); Decisione (UE) 2021/914 (clausole contrattuali tipo); Raccomandazioni EDPB 01/2020 sulle misure supplementari; Raccomandazioni EDPB 02/2020 sulle garanzie essenziali europee |

> Non è un parere legale. Politica di default proposta (D08): **nessun trasferimento**; fornitori con region UE e,
> preferibilmente, senza sub-responsabili extra-SEE per i dati applicativi.

## 1. Albero decisionale

1. Il fornitore o un suo sub-responsabile tratta o **accede da remoto** (anche per supporto) a dati personali fuori dallo SEE?
   No → nessun trasferimento; annotare "nessuno" nel registro. Sì → punto 2.
2. Il paese gode di una decisione di adeguatezza (art. 45)? Per gli Stati Uniti: il destinatario è **certificato** nel
   Data Privacy Framework (verificare sul sito ufficiale DPF e conservare lo screenshot datato)?
   Sì → trasferimento ammesso; documentare la verifica, ripeterla annualmente. No → punto 3.
3. Clausole contrattuali tipo (Decisione 2021/914, modulo corretto: 2 titolare→responsabile, 3 responsabile→sub-responsabile)
   o altra garanzia dell'art. 46 → **TIA obbligatoria** (§2) e misure supplementari se necessarie.
4. Deroghe dell'art. 49 → solo per trasferimenti occasionali; **non adatte** a un servizio continuativo.

## 2. Modello di Transfer Impact Assessment (TIA)

| Passo (EDPB 01/2020) | Contenuto [DA COMPILARE per fornitore] |
|---|---|
| 1. Mappatura | Esportatore, importatore, paese, categorie di dati e interessati (minori sì/no), finalità, formato, frequenza, accesso remoto o conservazione |
| 2. Strumento | Adeguatezza / CCT (modulo) / altro |
| 3. Valutazione del diritto del paese terzo | Leggi sull'accesso delle autorità pubbliche applicabili all'importatore; prassi; garanzie di ricorso. Fonti consultate e data |
| 4. Misure supplementari | Tecniche (cifratura con chiavi nel SEE, pseudonimizzazione, minimizzazione dei campi); contrattuali (obbligo di notifica e contestazione delle richieste, trasparenza report); organizzative (policy, minimizzazione degli accessi del supporto) |
| 5. Passi procedurali | Firma delle CCT; aggiornamento del registro e delle informative (§7) |
| 6. Riesame | Data del riesame [DA COMPILARE]; eventi che lo anticipano (sentenze, nuove leggi, cambio sub-responsabili) |
| Esito | ☐ trasferimento ammesso ☐ ammesso con misure ☐ non ammesso — scegliere un altro fornitore |
