# Onboarding delle famiglie (procedura per il centro + guida rapida)

## Per il centro
1. Registra studente e tutore legale; verifica la relazione (documento/evidenza) come da procedura privacy.
2. Crea l’invito con ruolo *Tutore legale*, studente e permessi della delega (gestione disponibilità, richieste di modifica, notifiche).
3. L’invito parte via email con link `/invito#token=…` (valido poche ore, monouso). Se scade, «Reinvia».
4. Alla scadenza della delega il portale mostra la data di riconferma sulla scheda del figlio.

## Guida rapida da inviare alla famiglia
1. Apri il link dell’invito e scegli una password (almeno 12 caratteri, meglio una frase).
2. Hai già un account? Scegli «Ho già un account» e accedi: l’invito si attiva automaticamente.
3. Dopo l’accesso trovi una scheda per ogni figlio. «Sola lettura» = puoi vedere ma non modificare.
4. Per assenze o cambi: «La mia settimana» → lezione → «Segnala assenza» / «Chiedi un cambio».
5. Per il calendario sul telefono: Impostazioni → Calendario → «Crea link» (copialo subito, si vede una volta).
6. Problemi di accesso: «Password dimenticata?» nella pagina di accesso, oppure contatta il centro.

## Sicurezza dei link
- Il token dei link di invito e reset sta dopo il simbolo `#`: non viene inviato al server nei log né ai siti esterni, e l’app lo rimuove subito dalla barra degli indirizzi.
